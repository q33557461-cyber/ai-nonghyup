# AI첫걸음 — 농협 직원 전용 AI 질문 센터

농협 직원 AI 교육용 개인 시안입니다. 농협의 공식 서비스가 아닙니다.
- 부서와 업무를 고르고 상황을 한 줄 적으면, AI 대화창에 붙여 넣을 질문을 만들어 줍니다. 휴대폰에서 바로 쓸 수 있습니다.
- 처음 시작만 앱의 도움을 받고, 그다음은 AI 안에서 대화를 이어 가시면 됩니다.
- 입력한 내용은 이 페이지 안에서만 쓰이며 서버로 보내지 않습니다.
- 최근에 쓴 업무와 우리 조합 부서 이름만 이 기기 브라우저에 기억합니다. 질문·상황 글은 저장하지 않으며, 처음 화면 [기록 지우기]로 지울 수 있습니다.
- 실제 고객·조합원 이름, 전화번호, 계좌, 내부 자료는 넣지 마세요.
- 이전 판(v03, 엑셀 수식 포함)은 내려 두었습니다. 시험용 경로 `/v05/`는 같은 내용입니다.
